Airflow
------------ 
To reset the airflow db:
airflow db reset
To initalize the airflow db:
airflow db init


To create airflow user:

airflow users create \
   --username admin \
   --firstname First \
   --lastname Last \
   --role Admin \
   --email admin@example.com \
   --password newpassword123


Run command to start Airflow: 

airflow scheduler 

followed by to run the airflow webserver :

airflow webserver -port 8080

Airflow Web UI : http://localhost:8080/home
